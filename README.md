Financial-Controlling Dashboard – Datenharmonisierung & KPI‑Steuerung

Kurzbeschreibung:

In diesem Projekt habe ich ein zentrales Problem im Finanzbereich gelöst: Die Finanzdaten kamen aus unterschiedlichen Systemen, waren teilweise unvollständig oder widersprüchlich und mussten manuell gepflegt werden. Dadurch fehlte ein verlässliches Gesamtbild für Entscheidungen.
Mein Beitrag:

• Zusammenführung, Bereinigung und Harmonisierung von Finanzdaten aus mehreren Quellen
• Aufbau eines konsistenten Datenmodells (Power BI / Fabric / DAX)
• Entwicklung interaktiver Dashboards zu Revenue, EBIT, Kostenarten & Abweichungsanalysen
• Erstellung von Monats‑ und Jahresvergleichen sowie Forecast‑Strukturen
• Automatisierung von Berichten zur Reduzierung des manuellen Aufwands

Ergebnis / Mehrwert:

• Klare Transparenz über finanzielle Entwicklungen und Risiken
• Sofortige Erkennung von KPI‑Verbesserungen und Kostentreibern
• Weniger Fehler, weniger manuelle Arbeit, deutlich schnellere Entscheidungen
• Bereitstellung eines zuverlässigen Controlling‑Werkzeugs für das Management
